# Original website artwork

Generated specifically for this project using built-in image generation. No external characters, logos or stock artwork. WebP assets are locally hosted. These are decorative 3D-style illustrations, not scientific diagrams.

Prompt briefs:
- `scientist.webp`: original modest eight-year-old girl scientist in lavender hijab, white long-sleeved lab coat and full-length lilac dress; magnifying glass, seedling, rabbit, turquoise songbird and butterflies in an educational garden; friendly 3D anime style, no text.
- `ecosystem.webp`: cute rabbit eating grass, turquoise songbird, butterflies, flowers and pond; miniature ecosystem in a pastel 3D anime landscape; no text.
- `earth.webp`: layered rocks and soil, roots, plant seedlings, fossil shell, mountains and inactive volcano; child-friendly 3D landscape; no text.
