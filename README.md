# عالم العلوم الممتع

تجربة عربية مخصّصة لموضوعات منهج العلوم للصف الثالث الابتدائي، الفصل الأول فقط.

الموقع: https://ah127hasan-tech.github.io/science-grade3-games/

- ٣ وحدات، و١٢ درسًا، و٩٦ نشاطًا.
- لكل درس: اختيار من متعدد، صح أو خطأ، ترتيب مراحل، تطابق كروت، متشابهات، سحب وإفلات، تصنيف، وألغاز.
- رسومات أصلية بأسلوب أنمي ثلاثي الأبعاد، وعبارات تشجيعية، وأصوات أصلية مصنّعة برمجيًا تشمل التصفيق.
- يعمل الصوت بعد أول تفاعل، ويمكن كتمه. يتوفر بديل للسحب: اختيار البطاقة ثم مكانها.
- يحفظ أفضل نجوم لكل نشاط على نفس المتصفح، ويحافظ على عدّاد النجوم من النسخة السابقة. قد لا يتوفر الحفظ في بعض إعدادات المتصفح.
- لا تسجيل دخول ولا مؤقت. الأنشطة تدريبية أصلية، وليست نص الكتاب الرسمي.

## فحص التطوير

من مجلد المستودع:

```sh
node tests/games.cjs
node tests/sound.cjs
node tests/storage.cjs
```

`lessons.js` يحفظ محتوى الدروس الأصلية. الإضافات في `activities.js`، والتفاعل في `app.js`، والتصميم في `arena.css`، والصوت في `sound.js`. لا يحتاج الموقع إلى بناء أو مكتبات خارجية.
